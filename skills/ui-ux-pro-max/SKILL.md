# ui-ux-pro-max

1. Identify audience, product purpose, existing brand and implementation stack. Use frontend-design for distinctive visual direction and UI/UX Pro Max for product/platform matching.
2. Query the bundled search script by full path. Choose --design-system for a new visual system, --domain for a focused concern, or --stack for implementation patterns.
3. Combine intentional layout, typography and imagery with responsive behavior, accessible interaction states and platform conventions. Treat catalog suggestions as adaptable recommendations.
4. Preserve existing design systems. Check actual narrow/wide layouts, text reflow, focus, loading/error/empty states and reduced-motion behavior.
5. Use web-design-guidelines for focused web audits, react-expert for React implementation and roblox-ui-implementation for Roblox's engine-specific UI.
